# Emerald Engine – GameMaker 2D RPG Hazır Paketi

Bu paket Zümrüt Çiçeği oyununun temel mekaniklerini ve hazır assetlerini içermektedir. Oyun geliştirmek isteyen ancak sıfırdan karmaşık sistemler kodlamakla vakit kaybetmek istemeyen herkes için envanter, diyalog, craft ve hayatta kalma gibi geniş çaplı bir mekanik havuzu sunar. Geliştirici, tamamen Türkçe komutlar ve fonksiyonlar sayesinde sistemi dakikalar içinde kavramaya başlayabilir.

## Nasıl Kurulur?

1. Sayfanın sağ tarafında yer alan Releases bölümünden son sürüme tıklayın.
2. Açılan sayfadaki Emerald.Engine.v1.yymps dosyasını bilgisayarınıza indirin.
3. GameMaker üst menüsünden Tools -> Import Local Package yolunu izleyin ve indirdiğiniz .yymps dosyasını seçin.
4. Açılan aktarım penceresinde Import butonuna tıklayarak projenin kurulacağı klasörü belirleyin.
5. Proje açıldığında sağ üstteki menü simgesine basıp Game Options penceresini açın.
6. Pencerenin alt kısmında yer alan "Automatically remove unused assets when compiling" seçeneğindeki tiki mutlaka kaldırın ve Apply diyerek kaydedin.
7. Artık F5 tuşuna basarak motorun ilk açılışını test edebilirsiniz.

## Eğitim

Sistemin tüm detaylarını, komut yapısını ve adım adım nasıl kendi oyununuza uyarlayacağınızı Atık Adam YouTube kanalındaki video serisinden takip edebilirsiniz.
